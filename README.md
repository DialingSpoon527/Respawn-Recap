# Respawn Recap

An Outer Wilds-inspired client-side respawn animation for Minecraft.

![Respawn Recap](media/respawn-recap-demo.gif)

Screenshots are saved periodically as you play the game. Then, upon death, the mod replays your memories in an Outer Wilds-inspired Nomai memory-download animation.

Screenshots are cleared each time the replay happens and are thinned out to not accumulate beyond 300. However, this still amounts to about 100 MB (0.1 GB) per world. The storage location can be found at `.minecraft/respawnrecap/replay/<worldname_worldid>`. It also contains a backup of the last recording you saw if you would like to review it after you've watched it. I would recommend deleting these recordings if you find you need space on your computer.
